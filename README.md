Welcome to the GitHub repository for our project titled: "Global Patterns of Psychological Coping and Institutional Trust During COVID-19". 
This repository contains all materials related to our analyses based on the publicly available COVIDiSTRESS Global Survey dataset.

What you'll find in this repository
- original-paper
  This folder includes the original paper, along with supporting documents from the dataset creators—such as the full list of variables, the original questionnaires, and background information on the COVIDiSTRESS Global Survey.

- analyses
  All R scripts used in our project are collected here. This includes the full analysis pipeline: from data cleaning and exploratory factor analysis (EFA) to cluster analysis, network models, and continent-specific regressions. 
  Each script is commented to make it as readable and reproducible as possible.

- results
  This folder contains visual summaries of our findings, including factor structures, cluster distributions, network graphs, and regression outputs. 
  These figures were used to support the interpretations in the paper.
